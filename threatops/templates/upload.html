Upload Security Logs (CSV)

Upload CSV files to automatically correlate threats using stored procedures. Triggers will log the upload to audit trail.

Required CSV Headers
  • timestamp - Format: YYYY-MM-DD HH:MM:SS
  • source_ip - Source IP address
  • destination_ip - Destination IP address
  • protocol - Protocol (TCP, UDP, HTTP, etc.)
  • port - Port number (1-65535)
  • event_description - Description of the event
  • severity - Low, Medium, High, or Critical
Note: Upload uses transactions (START TRANSACTION/ROLLBACK/COMMIT). The CORRELATE_THREAT stored procedure will automatically map logs to MITRE techniques, and GENERATE_ALERT will create alerts. Triggers will audit the upload.
