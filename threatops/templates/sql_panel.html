{% if session.role == 'Admin' %}
Administrator Privileges

As an Admin, you have unrestricted database access for system management and maintenance:

✅ Allowed Operations (Full Access):
  • DQL (Data Query Language): SELECT
    • Aggregate Functions — COUNT, AVG, SUM, MIN, MAX with GROUP BY, HAVING
    • Set Operations — UNION, INTERSECT (via IN), EXCEPT (via NOT IN)
    • Subqueries — Scalar, Correlated, Nested
    • Joins — INNER JOIN, LEFT JOIN, CROSS JOIN
  • DML (Data Manipulation): INSERT, UPDATE, DELETE
  • DDL (Data Definition): CREATE, ALTER, DROP, TRUNCATE
    • Constraints — PRIMARY KEY, FOREIGN KEY, CHECK, UNIQUE, NOT NULL
    • Views — CREATE VIEW, DROP VIEW
  • DCL (Data Control): GRANT, REVOKE
  • TCL (Transaction Control): COMMIT, ROLLBACK, SAVEPOINT
  • Procedural SQL:
    • Stored Procedures — CALL, CREATE PROCEDURE
    • User-Defined Functions — CREATE FUNCTION
    • Triggers — BEFORE/AFTER INSERT, UPDATE, DELETE
    • Cursors — Cursor-based row processing
🎯 Admin Responsibilities:
  • Database Management: Create/modify schemas, tables, views & constraints
  • User Administration: Grant/revoke permissions, manage analyst accounts
  • Data Governance: Maintain referential integrity, manage MITRE frameworks
  • Query & Analytics: Complex joins, aggregations, subqueries for threat analysis
  • Automation: Manage stored procedures, functions, triggers & cursors
  • Transaction Control: Manage commits, rollbacks & savepoints for data safety
  • System Maintenance: Backup operations, schema updates, index optimization
  • Audit & Compliance: Review all system activities, investigate incidents
⚠️ With great power comes great responsibility: All Admin queries are logged to AUDIT_LOGS for compliance and security auditing. Exercise caution when executing DDL/DML commands.
